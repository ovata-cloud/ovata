# 品牌調查與缺資料處理

用於撰寫或補強品牌頁、商品頁與購買說明。先找到支持顧客決策的真實內容，再決定版面；公開資料不足不代表可以自行補寫事實。

## 先查官方資料

- 核對品牌名稱、地點與官方帳號，查現有官網、FB／IG、商品照片、包裝及實際購買入口。沒有既有品牌時，可用一個貼近客群與商業模式的競品參考結構，不挪用其事實、文案或素材。
- 記錄原始網址、發布／查閱日期、可確認內容與尚待確認事項；區分品牌公告、歷史刊登、分店與經銷商資料。遇到新版公告，以日期判斷適用性，不把已下架賣場或過期促銷當現行規則。
- 來源無法存取時，記錄限制並找其他官方來源；未找到不等於不存在。只看到社群帳號不算完成調查，應實際讀取可取得的內容及照片。
- 優先將真實商品、包裝與店家照片放入內部提案，記錄素材出處及使用權待確認事項。公開可見不等於已取得正式商用授權。

## 依頁面補內容

| 頁面 | 要找的資料 |
| --- | --- |
| 品牌故事 | 官方介紹、創立背景、人物與可查證的傳承／製作故事、店家與商品照片；只保留對客群有意義的內容 |
| 商品 | 現行品項、實拍、價格、規格、內容物與必要標示；食品另查成分、過敏原、保存和加熱標示 |
| 怎麼買 | 現行訂購入口／通路、付款方式、配送範圍、運費與免運條件、出貨時間、自取安排、取消／售後與客服方式 |

交易條件以該品牌的有效說明為依據，不套平台預設規則、競品條件或經銷商政策。食品的保存與加熱步驟依實際品項標示，不能把某篇貼文的一個時間當成所有商品通則。

## 資訊不足時

1. 列出缺項及影響的頁面，區分「尚未找到」「舊資料待更新」「需要店家確認」。已有答案不重問，不為等資料停下其他可完成的工作。
2. 整理一封可直接回覆的索資信，說明用途、已確認資料與少量必要缺項，接受店家提供現有連結、文件或照片，不要求重填已知資訊。有寄送授權時透過既有對客管道發送；沒有時先留可審核草稿，不假稱已聯絡。
3. 內部提案可保留具體欄位，例如「運費與免運條件：待店家提供」，讓使用者知道要補什麼。內容仍不足以成頁時，先不開放該頁；已指定保留的頁面則明確標示待補。
4. 不用通用三步驟、空泛品牌文案、虛構歷史或猜測的政策填版面。待補欄位不是正式顧客說明；對外交付前確認資料或移除未完成頁面。

## 交付前核對

品牌主張、故事與交易條件皆有可追溯來源；歷史資料有標示，失效入口沒有被當成可購買；缺項可直接交給店家補充。每個獨立頁都要有支持其任務的實質內容，不為湊頁數建立薄弱頁面。
